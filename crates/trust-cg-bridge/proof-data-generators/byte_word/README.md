These are untrusted CIC proof-DATA constructors for the fixed frame package.
They return terms, never a checked wrapper, proof grade or compiler license.
`proof_pair` constructs the seven universal eight-bit Nat-shift laws;
`reassembly::proof_pair` constructs full64 little-endian reassembly using those
checked declarations, Bool.rec and List congruence. All public input bits are
arbitrary. Each result requires the real independent kernel check.

This directory is a path-included generation module, not a new runtime
dependency or standalone Cargo graph. Use one matching `clean_kernel` namespace
and the qualified generation recipes/readsets in the frame23 handoff. The
runtime reader uses ONLY the retained packets under
`src/verify_output_instantiate/memory_reflection/frame_bank`, restores/matches
and checks them; it never calls these constructors. R's constructive SP/offset
source is `src/original_frame_arithmetic.rs`. Other generation-driver source,
commands, original failures and actual checker/artifact identities are retained
in the source-bound handoff; no source-path relocation relabels old evidence.

These source bodies come from the qualified math-producer sources retained in
the owned Clean-tool prototype, formatted with the Trust configuration. The
source-relocation and same-formatter-output receipts preserve both identities. They live here because no
Clean kernel/API or dependency-pin change is needed for this proof-data package.
They are not production Rust/THIR semantics, physical ABI, legal-frame/world,
SourceNoUB, body licensing, unwind or admission evidence.
