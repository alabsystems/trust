# Actual source-entry transport controls

Build `Cargo.observer.toml.in` in an owned external directory using genuine
`targo --unverified rustc`, the seed compiler that built the supplied completed
SDK's private crates, and the exact private dependency pairs from that SDK's
installed driver closure. Then run `../source_word64_metadata_test.py` with
`--observer`, `--targo`, `--sysroot` and a fresh `--out`. Hold the original
SDK/input leases and machine admission through both phases. Never mix private
crate namespaces, override global compiler flags or relabel an older SDK.

The fixed four-case source roster requires actual upstream entries for identity,
self-addition, two-parameter addition and a source form containing statements.
The first three retain original source claims; the unsupported fourth remains
unavailable. The crate-store observer checks owner, original source-file hash,
parameter/call operands, agreement with actual D28 callee identities, actual
retained D28 evidence, and rejects a changed
source owner even after recomputing the complete envelope digest. It retains
actual original and changed entry bytes. The observer and producer must report
the same full compiler source commit.

These are source-data transport tests, not Rust-source TV, source authenticity,
purity, termination, ABI, NoUB, a caller companion or codegen admission. An
arbitrary same-owner rehashed claim remains untrusted. A fifth inline
`#[track_caller]` control must keep its named caller-location refusal, showing
that the wider transport preserves the legacy refusal inventory. Every run
retains input copies/hashes before compilation, including on failure. Qualifying this fixture
does not qualify all compiler tests or the full SDK.

The ordinary-call controls additionally retain the real core callee's complete
entry, unchanged IR module and bounded original-source claim. The source must
name the actual compiler-registered wrapping-add intrinsic with the original
two operands. Both callers must observe identical callee inputs. Actual producer
and consumer modes remain disclosed separately; data decoding does not admit a
mode mismatch. These paired inputs prepare independent mathematics without
minting Rust-source TV or source authenticity.
