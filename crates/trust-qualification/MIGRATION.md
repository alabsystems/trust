The original boundary investigation was at
`05626792b070e322223b2c2ada94440b7b0a3404`. Native metadata ownership now has a
real implementation and consumer, separate from workload qualification.

The new route is separately negotiated `sealed-metadata-v1`, with
`context_sdk:inherited-sdk-keeper-v1` and a `native-metadata-ready-v1` lookup
inside the already registered root. The fixed capabilities object is negotiated
there, with no preliminary metadata capability child outside durable ARM.
Generic SDK/context lookup never enables sealed members. Existing
ordinary context/telemetry codec cutover remains a separate concern; there is
no legacy retry or field stripping. The host retains the actual service SDK
GC lease/selection independently from both target roots. Kinds12/13/14 carry
the member request, held input observations and post-drain actual outcome.
Cancellation uses the transferred event socket. After the handshake closes,
original pinned-host validation replaces closed-socket peer-credential reads;
it does not reselect a host. Shared descriptor transfer is the same native
implementation used by ordinary GNU/CPU handoffs.

One finite native Targo service invocation accepts at most six closed probe
specs on a bounded regular stdin file and returns bounded native records. The
actual host owns occupied preparation, suspended image checks, no-fork/session
containment, original CPU/GNU/memory, cancellation, cohort retirement and
post-input checks. Durable cohort recovery, rather than EOF or leader exit,
controls original resource settlement after death. These are native governance
and closure facts, not a hard kernel memory quota. Keep all old compile,
foreign-phase, loader, retained-fixed and fence refusals.

Factor already-held capacity at its real native origin before descriptor reuse.
Constructors must require live checked CPU/GNU/memory origins, original host/boot,
debt/manifest validation and distinct root/member attempts. Nested callers and
registered members borrow existing CPU; only the independently checked original
root may take its initial-CPU route. A fresh pool, jobserver, private epoch or
environment advertisement is not this factorization.

The owner must bind exact regular program/runtime inputs, argv, cwd and explicit
environment before GO, using existing native loader validators where applicable.
Unsupported closure/platforms refuse. A pathname hash observation is not a
kernel-loaded-image capability. Keep original scope, streams and scheduling
owners through cancellation, drain, reaping and positively confirmed retirement.
`Attached` is not GO; helper exit is not target exit. Unknown delivery poisons
the logical unit and prevents replay or reuse of borrowed capacity.

`ReceiptCheckedPair` consumes the concrete runner for each seal's exact
`trustc -vV`, `trustc --print sysroot`, and genuine
`targo --unverified --version`. Rebind the complete original snapshot before and
after all probes, including failures. Retain runner/program/output identities,
finite byte/time bounds and actual exit/signal/cleanup facts. Refuse malformed
or repeated commit fields, foreign sysroots and non-genuine Targo. Label and
byte consistency grants no source, writer, build, proof or release authority.
The same actual capacity/cohort and bounded process primitives must serve later
workloads. Metadata's closed argv must remain closed; workloads require their
own validated native purpose, not a wider metadata exception. Frontend Git and
input preparation remain explicitly outside this metadata-only admission.

## Qualification and deletion

Retain original controls and exact failed inputs/binaries before repair. Qualify
actual admitted roots and nested members, host/boot/debt/manifest replacement,
parent forgery, descriptor alias/reuse, retained-fixed/fence refusals and parent
death. Exercise genuine sealed SDK probes and changed commit/sysroot/tool
negatives, unsupported loaders, timeout/output limits, cancellation before/after
GO, escaped descendants, stream drain and unknown delivery without replay.
Use maintained interfaces without fabricating completed records or weakening
resource/grade policy.

For workloads also qualify source/config/dependency drift, omitted/truncated or
disagreeing AY censuses, proof identity changes, native artifact substitution,
unequal/filtered inventories, writer death and ambiguous cleanup with actual
build/output locks retained.

Delete a helper only when its entire policy is native, all active production
callers invoke that owner, and the original meaningful regression population
has migrated without omitted cases. Promotion/recreation/other callers must
migrate before deleting shared Python seal/receipt readers; all build,
measurement and cleanup callers must migrate before deleting the lock facade.
Remove superseded helper tests and compatibility entrypoints with their
implementation. Retaining wrappers, another script or narrower workflow
coverage does not meet the owner's deletion condition. Current input/receipt,
metadata and saved-census components meet none of these complete-retirement
conditions on their own.
