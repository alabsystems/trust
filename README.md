# trust

Trusted Rust +  Lean compiler toolchain for AI. Faster, fixes your bugs, drop-in works for all Rust and Lean.

trust is made by [ALab](https://alab.systems). Its source code is not published:
this repository carries trust's binary releases, their release notes, and its
license.

## Install

Install it with aterm's package manager, which verifies every signed binary:

```sh
aterm pkg install trust
```

Every release is listed under [Releases](https://github.com/alabsystems/trust/releases),
and its notes are in `release-notes/`.

## Security

Report a security problem privately to hello@alab.systems, not in a public
issue.
