# Pin-coherence waivers, read by scripts/hooks-pin/pre-push.
#
# A row means: this submodule is knowingly off its recorded pin. The pre-push
# pin gate steps over the listed path and blocks on every other drift. It is
# per-path on purpose: a whole-gate quarantine would also waive the next drift,
# which is the one the gate exists to catch.
#
# Format (`|`-separated, one row per line):
#     <submodule path> | <expires YYYY-MM-DD> | <owner> | <reason>
#
# The hook enforces, so a row cannot rot:
#   * past `expires`, the row stops applying and the drift blocks again;
#   * once the path is back at its pin, the row fails the push until deleted.
#
# Fix drift rather than waive it:
#     scripts/submodule_sync.sh              # classify, read-only
#     scripts/submodule_sync.sh --restore    # BEHIND, plus AHEAD/DIVERGENT whose
#                                            # every unique commit is held by a
#                                            # durable ref (ANCHORED); refuses others
#
# No active rows: every drift blocks.
