# Pin-coherence waivers, read by scripts/hooks-pin/pre-push.
#
# A row here means: "this submodule is knowingly off its recorded pin, someone
# owns it, and it is not the pushing lane's fault." The pre-push pin gate steps
# over the listed path and BLOCKS on every other drift. It is per-path on
# purpose — a whole-gate quarantine would waive the next drift too, which is the
# only drift the gate exists to catch.
#
# Format (`|`-separated, one row per line):
#     <submodule path> | <expires YYYY-MM-DD> | <owner> | <reason>
#
# Rules the hook enforces mechanically, so a row cannot rot:
#   * past `expires_on`, the row stops applying and the drift blocks again;
#   * once the path is back AT its pin, the row FAILS the push until deleted.
#
# Adding a row is a decision, not a workaround. If the drift is yours, fix it:
#     scripts/submodule_sync.sh              # classify, read-only
#     scripts/submodule_sync.sh --restore    # BEHIND, plus AHEAD/DIVERGENT whose
#                                            # every unique commit is held by a
#                                            # durable ref (ANCHORED); refuses others
