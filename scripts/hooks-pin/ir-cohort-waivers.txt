# IR-cohort waivers, read by scripts/check_ir_cohort.py.
#
# A row means: this part of the cohort is knowingly on a different trust-ir
# semantics (schema digest) from the ratified one, which is the schema at the
# superproject's recorded gitlink for that dependency. The gate steps over the
# listed schema and blocks on every other divergence. It is per-schema on
# purpose: a whole-gate quarantine would also waive the next divergence, which
# is the one the gate exists to catch.
#
# Format (`|`-separated, one row per line):
#     <dependency> | <schema digest> | <expires YYYY-MM-DD> | <owner> | <reason>
#
# The gate enforces, so a row cannot rot:
#   * past `expires`, the row stops applying and the divergence blocks again;
#   * once the divergence is gone, the row fails the gate until it is deleted.
#
# Not waivable by any row: a revision that does not resolve, and a revision not
# contained in the dependency's origin/main (a fork: consumers on divergent
# branches can disagree arbitrarily while both look current). Containment needs
# a readable origin/main; without one the gate reports CONTAINMENT UNRESOLVED
# (re-run with --fetch), which blocks the same way but is not a finding of a
# fork. Without --fetch, an OFF-MAIN verdict is only as current as the local
# origin/main ref.
#
# The gate keys on the digest, not the revision: different commits with the
# same surface are safe to mix and need no row. A row closes when its consumers
# move forward to the ratified schema (a commit in the consumer, then the pin
# move here); the gate then fails until the row is deleted.
